# 스와이프 한글 키보드

자음 키를 **밀어서** 모음을 붙이는 안드로이드 한글 키보드(IME)입니다.
글자 하나(자음+모음)를 손가락 한 번으로 입력합니다.

## 자판

```
 Eng    ㄱ   ㄴ   ㄷ   ⌫
 숫자   ㄹ   ㅁ   ㅇ   반복
 기호   ㅂ   ㅅ   ㅈ   모음
(ㅋ     ㅌ   ㅊ   ㅍ   ㅎ)    ← 5줄 모드
 4/5줄  ⇦   ␣    ⇨   ↵
```

## 입력 방법

| 동작 | 결과 |
|---|---|
| 자음 키를 밀기 | 그 방향의 모음이 붙은 음절 |
| 자음 키를 탭 | 앞 글자의 받침 (붙을 수 없으면 낱자 ㄱ) |
| 다른 자음을 이어 탭 | 겹받침 (ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ) |
| 밀었다가 자음으로 되돌아오기 | ㅑ ㅕ ㅛ ㅠ ㅒ ㅖ |
| 밀다가 꺾기 | 겹모음 |
| 두 칸 옆 자음 키까지 끌기 | 거센소리: ㄱ→ㄷ ㅋ, ㄷ→ㄱ ㅌ, ㅂ→ㅈ ㅍ, ㅈ→ㅂ ㅊ, ㅇ→ㄹ ㅎ |
| 두 칸 아래/위 자음 키까지 끌기 | 된소리: ㄱ→ㅂ ㄲ, ㄷ→ㅈ ㄸ, ㅂ→ㄱ ㅃ, ㅈ→ㄷ ㅉ, ㅅ→ㄴ ㅆ |
| 끈 뒤 이어서 밀기 | 모음이 붙음 (ㄱ→ㄷ 끈 뒤 ↓ = 쿠) |
| 자음을 잠깐 누른 뒤 밀기·떼기 | 거센소리 (ㅅ은 ㅆ) |
| `4줄/5줄` | 5줄 모드에서는 ㅋ ㅌ ㅊ ㅍ ㅎ 줄이 따로 생김 |
| `반복` | 된소리로 (가→까, 각→갂, 잇→있), 안 되면 글자 반복 (ㅋ→ㅋㅋ) |
| `모음` 탭 후 자음 밀기 | 모음 낱자 (ㅠㅠ, ㅡㅡ), 앞 모음과 합치기 (고 + ㅏ → 과) |
| `모음` 밀기 | ↖^ ↗? ←, →. ↙! |
| `숫자` / `기호` 밀기 | ↑↗→↘↓ 순서로 1~5 / 6~0, 탭하면 숫자·기호 자판 |
| `↵` 밀기 | ↖' ↗" ←~ |
| `⇦` `⇨` / 스페이스 좌우로 밀기 | 커서 이동 |
| `⌫` 왼쪽으로 밀기 / 누르고 있기 | 단어 지우기 / 연속 지우기 |

방향별 모음:

```
 ↖ㅔ   ↑ㅗ   ↗ㅐ
 ←ㅓ   자음   →ㅏ
 ↙ㅡ   ↓ㅜ   ↘ㅣ
```

꺾기: `↑→` ㅘ · `↑↗` ㅙ · `↑↘` ㅚ · `↓←` ㅝ · `↓↖` ㅞ · `↓↘` ㅟ · `↙↘` ㅢ

예) **한글** = ㅇ→ㄹ로 끈 뒤 → 밀기(하), ㄴ 탭, ㄱ을 ↙ 밀기, ㄹ 탭

스와이프가 항상 새 음절을 만들기 때문에, 일반 두벌식처럼 받침이 다음 글자로
넘어가는 일(각 + ㅏ → 가가)이 없습니다. 밀고 있는 동안 입력될 글자를 말풍선으로 보여줍니다.

## 빌드 / 설치

Android Studio로 열거나:

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug         # 연결된 기기에 설치
./gradlew test                 # 한글 조합·제스처 단위 테스트
```

설치 후 앱(스와이프 한글)을 열어 **키보드 설정 열기 → 켜기 → 입력 방법 선택** 순서로 활성화합니다.

## 구조

```
app/src/main/java/com/rotmast/swipehangul/
├── hangul/
│   ├── Jamo.kt              자모 테이블, 음절 조합, 겹모음/겹받침 규칙
│   ├── HangulComposer.kt    스와이프용 한글 오토마타 (자모 단위 지우기 포함)
│   └── TextEdit.kt          단어 지우기 범위 계산
├── gesture/
│   ├── SwipeClassifier.kt   터치 경로 → 탭 / 방향 / 꺾기 / 되돌아오기
│   └── SwipeVowels.kt       제스처 → 모음 매핑
├── ime/
│   ├── SwipeKeyboardService.kt  InputMethodService (입력창 반영)
│   ├── KeyboardView.kt          키 그리기, 멀티터치, 미리보기, 손가락 궤적
│   └── Layouts.kt               한글 / 영문 / 기호 자판
└── SetupActivity.kt         활성화 안내 + 테스트 입력창
```

`hangul/`과 `gesture/`는 안드로이드 의존성이 없는 순수 Kotlin이라 JVM 단위 테스트로 검증합니다.
